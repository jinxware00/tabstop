# Tabstop

**A coding typing-speed trainer for developers.**

Type real code snippets across ten programming and query languages, race against the clock, and track your speed, accuracy, and progress — right in your browser.

---

## At a glance

- **10 languages** — from Lua and Python to Rust, Go, and SQL
- **3 challenge modes** — Copy Code, Complete Snippet, and Error-Free Run
- **3 timer options** — 30, 60, or 120 seconds
- **3 difficulty levels** — Beginner, Intermediate, and Advanced

## Progress and settings

Tabstop stores your data in your browser's `localStorage`:

| Key | What it stores |
| --- | --- |
| `tabstop.sessions` | Up to 500 recent sessions |
| `tabstop.settings` | Sound, accent, and reduced-motion preferences |

A session is saved once, when it ends. Choosing **Retry** starts a new session.

- **Personal best:** the highest net WPM across saved sessions.
- **Average:** the mean across saved sessions.
- **Sound:** off by default.
- **Reduced motion:** follows your operating-system preference unless you override it.

SF Pro Display, regular (400), medium (500), and semibold (600).

Source files: https://github.com/sahibjotsaggu/San-Francisco-Pro-Fonts

The WOFF2 files retain the font's original name and copyright records. They contain Latin characters, punctuation, currency symbols, and arrows; other scripts use the system fallback. The UI loads these files through local CSS `@font-face` declarations with `font-display: swap`.
